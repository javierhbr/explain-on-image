# Icono de ExplainOnImage

Ilustración original creada con la herramienta integrada de generación de imágenes. El PNG de 1024 × 1024 se ha convertido a ICO e ICNS para la aplicación, sin modificaciones artísticas adicionales.

## Prompt final

Create the final opaque master of this app icon. Preserve exactly the same four bold ivory capture brackets and bold orange diagonal up-right arrow, centered at the same proportions. The entire square image, from edge to edge and in every space between the shapes, must be filled by one completely uniform opaque midnight navy color #1B334F. Remove the rounded tile boundary: navy fills all four canvas corners too. There must be NO transparency anywhere, NO gradients, NO texture, NO dark spots, NO vignette, NO glow, NO shadows. Three flat solid colors only: background navy #1B334F, brackets ivory #FFFDF7, arrow orange #FF8A3D. Crisp clean antialiased vector-like edges. No text or extra objects. This flat solid square raster is a desktop icon master, not a mockup.
